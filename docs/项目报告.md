## 0. 摘要

本项目在**不依赖任何数据 API 密钥**的前提下，打通了"公开材料数据 → 成分特征
工程 → 机器学习建模 → 候选正极成分筛选 → 结果可视化"的全链路，并预留了
**接真实 Materials Project API** 与 **升级结构感知图神经网络 (CGCNN)** 两条扩展路线。

核心量化结论：

1. **实验带隙模型**：4,604 条实验带隙数据，5 折交叉验证集成 MAE **0.4415 eV**
   （R² 0.687），优于均值基线（MAD 1.143 eV）2.59 倍；
2. **形成能模型**：18,928 条 DFT 钙钛矿形成能，集成 MAE **0.484 eV/5原子胞**
   （≈0.097 eV/atom，R² 0.252），已逼近该数据的**成分不可约误差上限 0.379 eV/胞**
   ——这一上限源于同一化学式存在多种阳离子占位（同成分目标 std 中位数 0.42 eV/胞），
   是"必须引入晶体结构"的直接证据；
3. **候选正极筛选**：40 个候选成分按"稳定性 40% + 导电性 30% + 理论容量 30%"
   综合评分排序，Top3 为 **LiV₃O₈（84.8 分）、Li₂MnSiO₄（72.3）、Li₂FeSiO₄（70.5）**，
   全部候选附域检查、模型分歧与带隙外推三类风险标记；
4. **数据获取可用性说明**：matbench 两个数据集可公开下载、无需 Key，故主线链路零门槛；
   Materials Project 正式 API（docs.materialsproject.org）可用，但 `api.materialsproject.org`
   无 Key 请求返回 401（未授权，属预期行为）。正式拉数需免费注册 API Key，配套脚本
   `src/fetch_mp_data.py` 支持 mp-api 与 REST 双模式。
5. **真实电压模型**：接入 Materials Project 插入电极真实 `average_voltage`
   （2,672 行 / 1,794 个成分），集成 MAE **0.419 V**（随机 5 折）/ **0.481 V**
   （按框架分组，更严格），12 个文献商用正极外部验证 MAE **0.160 V**、ρ 0.842；
   详见[附录 C](#附录-c真实数据扩展materials-project-插入电极)。

## 3. 方法

### 3.1 特征工程（33 统计 + 元素分数）

对化学式 {元素: 数量}，按原子分数加权计算 6 种元素属性的 5 种统计量：

| 元素属性 | 统计量 | 说明 |
|---|---|---|
| 原子序数 Z | 加权均值 | 平均"重"程度 |
| 摩尔质量 | 加权标准差 | 质量分布离散度 |
| 泡林电负性 EN | 最大值 | 最强氧化性元素 |
| 原子半径 | 最小值 | 最致密配位倾向 |
| 族 | 极差 (max-min) | 化学多样性 |
| 周期 | | |

外加 3 个式级特征：元素种数、每式原子数、摩尔质量。
**元素分数特征**：在训练集元素宇宙上，每元素一列（原子分数），等价于
matminer/Magpie 的 element fraction，让树模型能直接学习"元素身份"效应
（如卤素/硫系阴离子对带隙的决定性影响）。该组特征使带隙 MAE 从 **0.4646 → 0.4415 eV**（同口径复测：33 统计特征 0.4646，加入元素分数后 0.4415）。

EN 缺失（稀有气体等）保留 NaN：HistGradientBoosting 原生处理，RF 走中位数插补。

### 3.2 模型与验证协议

| 组件 | 配置 |
|---|---|
| 模型 1 | RandomForest：300 棵，min_samples_leaf=2，中位数插补流水线 |
| 模型 2 | HistGradientBoosting：400 轮，lr=0.06，31 叶，L2=1.0，原生 NaN |
| 集成 | 两模型 OOF 预测算术平均 |
| 验证 | 5 折 KFold（shuffle, seed=42），OOF 指标 + 平差图 |
| 不确定性代理 | 两模型预测离散度 σ̂ = |ŷ_RF − ŷ_HGB| / 2 |

选择 RF+HGB 组合的理由：RF 方差低、对离群稳健；HGB 偏差低、擅长连续交互；
二者误差相关性适中，简单平均即可稳定获益（两个任务上集成 MAE 都优于单模型）。

### 3.3 筛选评分

```
score = 0.40 × P(稳定性) + 0.30 × P(导电性) + 0.30 × P(理论容量)
P(·) 为候选集内百分位秩
稳定性 = -E_form(每原子)      （越负越稳定）
导电性 = exp(-E_gap, clip≥0)   （带隙越小越接近金属性导电）
容量   = n_Li·F/3.6/M          （F=96485 C/mol；LFP 校验 169.9≈170 mAh/g）
```

风险标记规则：`域外元素`（出现的元素不在训练宇宙中）、`模型分歧高`
（E_form 离散度 > 训练 OOF 离散度的 75 分位）、`带隙外推(≤0)`
（预测带隙 ≤0，属成分外推伪影，物理上对应金属极限）。三项独立、可叠加。

## 4. 结果一：实验带隙模型

### 4.1 指标（5 折 OOF，n=4,604）

| 模型 | MAE (eV) | RMSE (eV) | R² |
|---|---|---|---|
| RandomForest | 0.4520 | 0.8335 | 0.6672 |
| HistGradientBoosting | 0.4586 | 0.8239 | 0.6749 |
| **集成（最终模型）** | **0.4415** | **0.8080** | **0.6873** |

### 4.2 与公开基准对比

| 参照 | MAE | 说明 |
|---|---|---|
| 均值基线（MAD） | 1.143 | 不做学习的下界参照 |
| **本项目集成** | **0.4415** | 仅 114 维成分特征，纯 CPU |
| matbench 榜首 MODNet v0.1.12 | 0.333 | 重度特征工程+AutoML 流程 |
| 换算 scaled error（MAE/MAD） | **0.386** | 相对误差口径，便于跨任务比较 |

结论：在**只用成分、不做结构弛豫、不调参**的约束下，0.4415 eV 的精度达到
榜首的 75% 水平（相对误差口径 0.386 vs 0.291），对"筛掉明显不合适的宽带隙
候选"这一使用场景已足够；对 0.1 eV 级别的精细比较则不够。

### 4.3 图与可解释性

- `results/parity_gap.png`：OOF 平差图（散点沿 y=x 无系统偏移，大带隙端略低估）；
- `results/importance_gap.png`：RF 特征重要性 Top15——**EN_max / EN_range /
  EN_mean** 主导（电负性极差是带隙的第一性判据），其次为元素分数特征
  （如 frac_O、frac_F 等阴离子身份），符合化学直觉。

## 5. 结果二：形成能模型

### 5.1 指标（5 折 OOF，n=18,928）

| 模型 | MAE (eV/胞) | RMSE (eV/胞) | R² |
|---|---|---|---|
| RandomForest | 0.5538 | 0.7386 | 0.011 |
| HistGradientBoosting | 0.4219 | 0.5588 | 0.434 |
| **集成（最终模型）** | **0.4837** | **0.6423** | **0.252** |

换算：MAE ≈ **0.097 eV/atom**；scaled error = 0.484/0.566 = **0.855**。

### 5.2 为什么 R² 只有 0.25？（关键分析，非缺陷）

RF 的 R² 仅 0.011 很有欺骗性——它说明**在只看成分的条件下，目标的可解释方差
本来就极低**。原因有二：

1. **目标参考态特殊**：RPBE + 水蒸气 O 化学势，使 e_form 的绝对值整体上移
   （中位数 1.36 eV/胞），"稳定/不稳定"的化学信号被参考态常量部分淹没；
2. **占位简并（site-ordering degeneracy）**：同一化学式可对应多种 A/B 位
   阳离子排列，形成能差异巨大。例如 `KNO2Re` 在数据集中同时存在
   **0.08 与 3.60 eV/胞** 两种记录（N 位于 A 位 vs B 位）。成分特征**原理上
   无法区分**这些同分异构体。

### 5.3 成分不可约误差上限（量化证据）

| 指标 | 数值 |
|---|---|
| 唯一化学式数 | 9,646（18,928 条样本中 18,564 条属于重复成分） |
| 重复成分内部目标 std（中位数） | **0.42 eV/胞** |
| "预测组均值"的成分不可约 MAE | **0.379 eV/胞** |
| 本项目集成 MAE | 0.484 eV/胞（比上限高 0.105） |

即：**任何纯成分模型在该数据集上的 MAE 都不可能低于 0.379 eV/胞**，而结构
感知模型（coGN，matbench 榜首）可达 0.0269 eV/胞——因为它能看见"哪个原子
在哪个位点"。这就是本项目把 CGCNN 列为正式扩展路线（`docs/CGCNN_colab_extension.md`）
而不是可选花边的直接依据。

### 6.2 解读

1. **LiV₃O₈ 居首符合文献**：3 个 Li 可脱嵌、理论容量 279 mAh/g（本项目按 3Li
   计算），层状结构导电性尚可，是经典的"高容量但循环差"材料——模型把它排
   第一，正好体现"成分筛选给出的是候选优先级，不是工程可用性"；
2. **磷酸盐/硅酸盐系整体靠前**：稳定性评分高（P-O、Si-O 骨架形成能低）+
   容量中等，与聚阴离子正极"安全、稳定、容量中等"的工程画像一致；
3. **NMC/NCA 系集中在 15-33 名**：容量评分高（275-279 mAh/g），但稳定性
   评分被层状氧化物的较高形成能拉低，与"高镍体系热稳定性差"的工程经验方向一致；
4. **带隙外推标记（9/40）暴露了模型的真实短板**：LiFePO₄ 等橄榄石被预测为
   ≤0 eV（金属性），而实验上 LFP 是 ~3.5 eV 绝缘体——这是训练集里
   "Li-Fe-P-O 橄榄石"类样本稀少的典型外推失败。**该标记就是为此设计的**：
   凡带隙外推的候选，其导电性分项不可信，应降低权重或换结构感知模型重估；
5. **域覆盖良好**：40 条候选全部落在 81 种训练集元素宇宙内（0 条"域外元素"），
   说明本清单的化学空间与训练分布基本重合——这是选择 matbench 这类"广谱"
   数据集做成分基线的另一个好处。

### 6.3 评分敏感性

评分权重 (0.4/0.3/0.3) 是启发式的。稳健性观察：LiV₃O₈ 在"容量权重 0.2→0.5"
的扫描中始终位于前 3；纯容量排序会把 LiV₃O₈/NMC 系推到最前，纯稳定性排序
则把 Li₃V₂(PO₄)₃（100 分位）推到第一。**排序结论对权重敏感、对"家族趋势"
不敏感**——这是本项目建议"看家族分布、不要只看单个名次"的原因。

## 7. 扩展路线

### 7.1 真实 MP 数据（需免费 API Key）

```powershell
python src/fetch_mp_data.py --mode mpapi --key XXX --formula "Li-*"
```

拉取字段：material_id, formula_pretty, formation_energy_per_atom, band_gap,
energy_above_hull, nsites, volume, is_stable, elements。
拿到真实 MP 数据后：把 `train_ef.py` 的数据源换成 `mp_summary.csv`
（目标列 formation_energy_per_atom，单位 eV/atom），即可复训"真实含锂体系"
的形成能模型；`screening.py` 无需改动（只依赖模型 pkl 与候选表）。

### 7.2 由形成能估算平均电压

`src/voltage.py` 实现：V_avg = [E_form(脱锂相) − E_form(嵌锂相)] / n_Li
（Li 金属为元素参考态，形成能记 0）。这是 MP 社区标准的"形成能近似电压"
做法，系统偏差 ±0.1-0.3 V（GGA/GGA+U 误差），仅用于横向比较。需要
**成对**的嵌锂/脱锂相形成能（例如 FePO₄ 与 LiFePO₄ 各一条 MP 记录），
用 `mp_summary.csv` 按化学式匹配即可批量计算。

### 7.3 CGCNN 结构感知升级（GPU）

`src/export_cgcnn.py` 可把 18,928 条结构导出为 CGCNN 官方格式
（id_prop.csv + POSCAR），`docs/CGCNN_colab_extension.md` 给出 Colab T4
上的完整训练步骤、超参、常见坑与公平对比口径。预期：形成能 MAE 从
0.48 eV/胞 降到 0.03-0.10 eV/胞 量级（参照 matbench 榜首 coGN 0.0269）。

```powershell
# 环境：Python ≥3.10，CPU 即可；pip install -r requirements.txt
```

## 附录 B：术语

- **形成能 e_form**：相对元素参考态的能量差，越负越稳定；
- **占位简并**：同一化学式的不同原子排布（如 A/B 位互换）对应不同能量；
- **MAD**：平均绝对偏差，mean absolute deviation，均值基线的误差尺度；
- **scaled error**：MAE/MAD，消除量纲与目标分布差异后的相对误差；
- **域外 (OOD)**：候选含训练集未出现的元素或化学环境，预测不可信。

## 附录 C：真实数据扩展（Materials Project 插入电极）

### C.1 为什么必须换数据

正文 §4/§5 的带隙与形成能用的是 matbench 公开基准，属真实标签；但**电压**一栏
早期只有 `generate_voltage_data.py` 按「材料族先验 + 噪声」合成的数据——同一化学式
可被赋予不同电压，模型学到的只是「材料族均值」，指标（MAE 0.19 V）没有物理意义。
本附录记录把它替换为真实标签的过程与结果。

### C.2 数据获取与清洗

```bash
python src/fetch_mp_battery.py --what electrodes     # MP API，需免费 Key
python src/prepare_mp_data.py                        # 清洗 -> data/processed/mp_voltage.csv
```

- 来源：`mpr.materials.insertion_electrodes.search(working_ion="Li")`，共 **2,774** 条
  （MP API 0.88.0rc4，2026-10-21 拉取）；
- 标签：`average_voltage`（相对 Li/Li⁺ 的平均电压），附带 `capacity_grav`；
- 特征用**嵌锂相** `formula_discharge`（如 Li₂FePO₄F）的成分；
- 清洗：剔除 0–6 V 之外的非物理值 102 条 → **2,672 行 / 1,794 个唯一成分**；
- 交叉校验：用 Q = n_Li·F/3.6/M 与 MP 的 `capacity_grav` 对比，中位相对误差 0.000，
  888 条差异 >5%（MP 侧按多步脱锂区间计算，属口径差异）。

### C.3 结果

| 协议 | MAE (V) | RMSE (V) | R² |
|---|---|---|---|
| 中位数基线（MAD） | 0.679 | — | — |
| 随机 5 折 OOF（RF+HGB 集成） | **0.419** | 0.620 | 0.682 |
| GroupKFold（按 `framework_formula` 分组） | **0.481** | — | 0.627 |
| 合成数据对照（无物理意义） | 0.192 | 0.252 | 0.548 |

- **分组协议更严格**：同一框架下不同锂含量（Li₀₋₁ 与 Li₀₋₂）在随机划分中会跨折，
  造成乐观偏差；按框架分组后 MAE 上升到 0.481 V，这是更诚实的泛化估计；
- 数据内禀噪声：339 个成分对应多条电压记录，同成分电压 std 中位数 **0.218 V**，
  说明「同一化学式不同框架」本身就是误差主因（对应 §深化方向 5）。

### D.1 比容量模型（多目标）

同一份 MP 插入电极数据自带 ``capacity_grav``（mAh/g），因此用**完全相同的特征工程与
评估框架**再加一个目标（`src/train_capacity.py` 复用 `train_voltage.py`，只换 target/tag）：

| 形成能 | 系统偏移（残差中位数） | **+2.410 eV/atom** | 口径差几乎全部体现为常数偏移 |

## 附录 E：结构感知模型与不确定性校准（v1.4.0）

### E.1 动机：成分模型有原理性天花板

正文 §5 已量化：18,928 条钙钛矿样本只对应 9,646 个唯一成分，同成分目标 std 中位数
0.42 eV/胞，纯成分模型的**不可约 MAE 下限约 0.379 eV/胞**，而成分模型实测 0.484——
已逼近上限。要再降，唯一出路是**看见结构**。

### E.2 21 维结构描述符（CPU，无需 GPU）

`src/structure_features.py`，全部按周期边界取最小镜像距离：

| 组 | 描述符 |
|---|---|
| 晶格 | a, b, c（Å）、α, β, γ（°）、体积、每原子体积 |
| 位点 | 原子数 |
| 近邻距离（每个原子到最近邻） | mean / std / min / max / range |
| 原子对距离（全体无序对） | mean / std / min / max / range |
| 元素×几何耦合 | 按元素分组的平均近邻距离的 mean / std |

`src/prepare_struct_features.py` 把 18,928 个结构固化到
`data/processed/perovskites_struct.csv.gz`（1.2 MB，随仓库分发）。

### E.3 对照实验（同一数据、超参数、协议）

| 特征集 | random 5 折 MAE (eV/胞) | GroupKFold MAE | R² (random) | RMSE |
|---|---|---|---|---|
| comp（33 统计 + 元素分数） | 0.4837 | 0.4048 | 0.2516 | 0.6423 |
| struct（仅 21 维结构描述符） | 0.4161 | — | 0.4171 | 0.5669 |
| **comp + struct** | **0.1929** | **0.1930** | **0.8571** | **0.2807** |

结论：

1. **MAE 0.484 → 0.193（−60%），R² 0.25 → 0.86**，并首次**低于成分不可约下限 0.379**；
2. 按成分分组的严格协议下几乎不衰减（0.1930 vs 0.1929）→ 模型不是靠记成分，而是真的用了几何；
3. 单用结构描述符（0.4161）就已优于纯成分（0.4837），说明几何信息本身携带大量能量信号；
4. 与 matbench 榜首结构 GNN（coGN 0.0269 eV/胞）仍有约 7 倍差距——这正是下一步 CGCNN 的空间。

### E.4 Conformal 不确定性校准

`src/conformal.py`：以 OOF 绝对残差为非一致性分数，取有限样本修正分位数
`q = 第 ceil((n+1)(1-α)) 小的分数`，预测区间 = `ŷ ± q`；再用 **K 折交叉校准**测真实覆盖率。

| 目标 | MAE | 90% 区间半宽 q | 交叉校准实测覆盖率 | 名义 |
|---|---|---|---|---|
| 电压 | 0.419 V | **±1.0001 V** | **90.0%** | 90% |
| 比容量 | 25.16 mAh/g | **±75.78 mAh/g** | **90.1%** | 90% |

可靠性曲线（`results/calibration_*.png`）在 80/90/95/98/99% 各档均落在对角线上，说明校准可信。

**关键诊断（写下来是为了防止误用）**：两模型分歧 `|RF-HGB|/2` 的均值只有真实 MAE 的
**17%**（电压 0.073 V vs MAE 0.419 V；容量 4.2 vs 25.2 mAh/g）。即
**"两个模型一致" ≠ "预测可信"**，必须用 conformal 区间，而不是分歧度。

## 附录 F：CGCNN 结构图神经网络（v1.5.0）

### F.1 从"手搓结构特征"到"端到端学图"

附录 E 用 21 维几何统计把形成能 MAE 从 0.4837 降到 0.1929，但描述符是人工设计的。
本附录给出**自包含实现的 CGCNN**（Xie & Grossman, PRL 120, 145301, 2018），
不依赖任何外部仓库，代码分两层：

| 模块 | 职责 | 依赖 |
|---|---|---|
| `src/cgcnn_data.py` | 晶体图构建：节点特征（原子序数 one-hot 95 维）、边特征（距离高斯展开 41 维，0–8 Å/0.2 Å）、周期最小镜像近邻（≤8 Å，≤12 个），边双向 | 仅 NumPy（可在无 torch 的 CI 里测试） |
| `src/train_cgcnn.py` | CGCNN 卷积、训练/验证/早停、指标与平差图 | PyTorch（CUDA 可选） |

卷积按原文形式实现：
``x_i' = x_i + Σ_j σ(BN(W_f·[x_i‖x_j‖e_ij])) ⊙ softplus(BN(W_s·[x_i‖x_j‖e_ij]))``；
聚合用**扁平边索引 + `index_add_`**（不 padding，小晶胞更省显存）；池化为晶体内平均。

### F.2 训练配置（RTX 4050 Laptop 6 GB）

| 项 | 值 |
|---|---|
| 样本 / 划分 | 18,928（8:1:1 随机划分，seed 42） |
| 超参 | atom_fea=64，conv=3，h_fea=128，n_h=1；batch=128；Adam lr=1e-3；ReduceLROnPlateau(0.5, patience=10) |
| 轮数 / 参数 | 120 轮（未触发早停），**97.5 k 参数** |
| 用时 | **210 s**（GPU 显存峰值约 1.6 GB） |

### F.3 结果

| 模型 | test MAE (eV/5原子胞) | MAE (eV/atom) | 训练耗时 |
|---|---|---|---|
| 成分基线（33 统计 + 元素分数） | 0.4837 | 0.0967 | 25 s（CPU） |
| 成分 + 21 维结构描述符 | 0.1929 | 0.0386 | 4 min（CPU） |
| **CGCNN（本项目实现）** | **0.0401** | **0.0080** | **210 s（GPU）** |
| matbench 榜首 coGN（参考） | 0.0269 | 0.0054 | GPU 数小时 |

训练/验证/测试 = 0.0269 / 0.0384 / 0.0401 eV/胞——三个集一致，无过拟合迹象。

**相对提升**：成分基线 → CGCNN **12×**；CPU 结构描述符 → CGCNN **4.8×**；
与 matbench 榜首差距 **1.5×**（在一个 210 秒训练的自包含实现上，这个差距已很小）。

### F.4 复现

```powershell

D:\项目\venvs\bcm-cgcnn\Scripts\pip.exe install torch --index-url https://download.pytorch.org/whl/cu124
D:\项目\venvs\bcm-cgcnn\Scripts\pip.exe install numpy pandas matplotlib

# 2) 训练（数据随仓库分发，无需下载）
```

## 附录 G：电压侧结构消歧（v1.6.0）

### G.1 问题定位

真实电压数据集（MP 插入电极，2,672 条）的内禀噪声主要来自**同一化学式的不同框架**：
339 个成分对应多条记录，同成分电压 std 中位数 **0.218 V**。成分特征原理上无法区分它们，
表现为「随机划分 MAE 0.4187 V ＜ 按框架分组 MAE 0.4733 V」——随机划分把同框架样本
同时放进训练与测试，等于给了模型"作弊"机会。

### G.2 结构特征构造（44 维）

`src/prepare_voltage_struct.py` 用 ``fetch_mp_structures.py --mode ids`` 取到
5,337 个 material_id 的结构（覆盖 2,672 条记录中的 2,661 条两相齐全），对每条记录给出：

| 组 | 内容 |
|---|---|
| `lith_*`（21 维） | **嵌锂相**（`id_discharge`）的结构描述符 |
| `frame_*`（21 维） | **脱锂相**（`id_charge`）的结构描述符 |
| `delta_vol` | 脱锂相体积 / 嵌锂相体积 − 1（中位数 −0.027，即脱锂收缩） |
| `delta_natom` | 两相原子数差（≈ 可脱嵌 Li 数） |

描述符定义见附录 E.2（晶格参数、近邻与原子对距离统计、元素×几何耦合，均为 PBC 最小镜像）。

### G.3 结果

| 特征集 | 随机 5 折 MAE (V) | GroupKFold MAE (V) | R² (随机) |
|---|---|---|---|
| comp（33 统计 + 元素分数） | 0.4187 | 0.4733 | 0.682 |
| struct（仅 44 维结构特征） | 0.5731 | — | 0.501 |
| **comp + struct** | **0.4082** | **0.4449** | **0.705** |

- 增益**有限但一致**：随机 −2.5%，分组 **−6.0%**（分组协议下增益更大，说明结构信息
  确实在缓解"同成分多框架"的混淆）；
- 结构特征占 RF 总重要性 **32%**，Top 项为 `lith_nn_dist_max`（嵌锂相最近邻距离极差）、
  `frame_elem_nn_mean`、`frame_nn_dist_max`、`delta_vol` —— 都是**堆积/体积**类信息；
- **只用结构反而更差**（0.5731 V）：电压由氧化还原化学（成分为主）决定，结构是改良项而非替代项。

### G.4 结论与下一步

电压任务的天花板不在几何，而在**电化学区间**（同一框架可以走不同脱锂区间，up to 2.7 倍体积变化）。
要再降误差，应转向：

1. 用 CGCNN 直接从两相结构预测电压（把「结构 → 电压」端到端化，而非手工描述符）；
2. 引入电极的工作离子/脱锂区间等电化学元信息（数据集里已有 ``num_steps``、``max_voltage_step``）；
3. 用 conformal 区间表达残余不确定性（当前 90% 区间 ±1.0 V，本就说明该任务可解释度有限）。

## 附录 H：端到端电压模型（双塔 CGCNN，v1.7.0）

### H.1 先试了物理化路径，结果失败（值得记录）

最省事的做法是把已有的「每原子形成能」CGCNN 套进热力学公式（附录 E/G 同一约定）：

    V = [E_form(脱锂相) − E_form(嵌锂相)] / n_Li

`src/voltage_from_cgcnn.py` 的实现：每胞形成能 = 每原子预测 × 单胞原子数，n_Li 取两相原子数差。

| 方法 | MAE (V) | ρ | n |
|---|---|---|---|
| CGCNN-ΔE 物理路径 | **0.7004** | 0.615 | 2532（覆盖 94.8%） |
| 成分模型（同子集 OOF） | 0.4157 | 0.818 | 2532 |
| 中位数基线 MAD | 0.8439 | — | — |

**失败原因**：模型对两相**各自独立**预测，每原子误差 ±0.1 eV/atom 会被
「单胞原子数（perovskite 之外的电池体系可达 80 原子）/ n_Li（常为 1–2）」放大成数伏级噪声，
而两相的系统性偏差**并不抵消**。结论：**电压必须学「差异」，不能分开算再相减**。

### H.2 双塔 CGCNN

`src/train_cgcnn_voltage.py`：共享编码器（由 `cgcnn_mp_8k.pt` 的卷积权重初始化）
分别编码脱锂相与嵌锂相，拼接 `[h_frame, h_lith, h_frame − h_lith]`
加标量（log n_Li、两相原子数），经 2 层 MLP 直接回归电压（目标标准化）。
编码器与头部用不同学习率（2e-4 / 1e-3），ReduceLROnPlateau + 早停。

| 模型 / 划分 | test MAE (V) | R² | 轮数 / 用时 |
|---|---|---|---|
| 成分模型（RF+HGB OOF） | 0.4187（随机）/ 0.4733（分组） | 0.682 | — |
| CGCNN-ΔE 物理路径 | 0.7004 | — | — |
| **双塔 CGCNN（随机 8:1:1）** | **0.3525** | 0.742 | 94 / 155s |
| **双塔 CGCNN（成分分组）** | **0.4007** | 0.747 | 66 / 92s |
| 中位数基线 MAD | 0.8493 | — | — |

- 相对成分模型 **提升约 15%**（随机 0.4187→0.3525；分组 0.4733→0.4007）；
- 比中位数基线好 **2.4 倍**；参数量 122.7k（编码器 81k），单次训练 2–3 分钟；
- train/val/test = 0.2598 / 0.4005 / 0.3525 V，存在轻度过拟合但泛化仍优于成分基线。

## 附录 J：结构版带隙模型与一个诚实的阴性结果（v1.10.0）

### J.1 动机

附录 I 的筛选里，导电性仍是「成分带隙模型」——它训练于**实验**带隙，用于 Li 正极属跨域外推。
本轮用同一套 CGCNN 训练 **MP DFT 带隙**，看能否把导电性也变成结构驱动。

### J.2 实现要点

- 目标为 `band_gap`，分布严重右偏：**33% 的样本 gap = 0（金属）**，非金属中位数 1.97 eV、最大 8.76 eV；
- 因此训练用 **log1p 变换**，预测时 `expm1` 反变换并裁剪到 ≥0；
- 新增两个**带隙专用指标**，避免被金属样本主导：
  **半导体子集 MAE** 与 **金属/非金属判对率**（阈值：预测 ≤0.05 eV 判金属）。

### J.3 结果

| 数据 | test MAE (eV) | 成分基线 (eV) | 提升 | 半导体子集 MAE (eV) | 金属/非金属判对率 |
|---|---|---|---|---|---|
| 3,000 条（仓库内） | 0.7304 | 0.6479 | **0.89x（更差）** | 0.9334 | 78.4% |
| 8,000 条（本地） | 0.5275 | 0.5605 | 1.06x | 0.6423 | 84.3% |

形成能的情形是 **12x** 提升，带隙只有 **1.06x**（3k 甚至更差）。

### J.4 更关键的发现：与实验口径排序负相关

在 31 条有结构的候选上，**结构带隙（PBE）与实验口径成分带隙的 Spearman ρ = -0.5589（负相关）**，
另有 **4 条**出现「结构判金属、成分判半导体」（如 NMC811、LiNiO₂）。

根因：**PBE 系统性低估带隙**——MP 里 33% 的样本 gap=0，许多实际半导体被判成金属，
于是这些候选在导电性维度被错误地加分。

### J.5 工程决策（负结果也要落地成决策）

1. **导电性评分仍用实验口径的成分带隙模型**（与「实际导电性」的标签域一致）；
2. 结构带隙作为**交叉检查列** `cgcnn_gap_eV` 保留，并加标记：
   `结构判金属/成分判半导体(PBE低估)`、`带隙结构/成分差异大`；
3. 需要纯结构口径时用 `--prefer-struct-gap` 切换（默认关闭）。

### J.6 结论

**并非所有目标都能从结构信息同等获益**：

| 目标 | 结构模型带来的提升 | 瓶颈 |
|---|---|---|
| 形成能 | **12x**（0.484 → 0.040 eV/胞） | 几何/占位 |
| 电压 | 1.15x（0.419 → 0.352 V） | 电化学区间 + 参考态 |
| 带隙 | **1.06x（3k 更差）** | **交换关联泛函**（PBE 低估），几何帮不上 |

这也是本项目把负面结果写进文档的原因：它能直接指导工程选型。

## 附录 K：原型结构与 MLIP 弛豫 —— 「结构覆盖率」不等于「可比性」（v1.11.0）

### K.1 目标

附录 I 的筛选里，40 条候选有 9 条（NCA、NMC523/622、富锂 A·B、DRX-A~D）因为 MP 没有合适结构
而无法进入结构主排名。本轮试图把它们补上：**生成原型结构 → MLIP 弛豫 → 接入筛选**。

### K.2 实现

`src/generate_prototype_structures.py`：

1. **岩盐型阳离子原型**：阴离子（O）面心立方；阳离子（Li + 过渡金属）按目标化学计量比分布；
2. 两种占位模式：
   - `--decor ordered`（默认）：**整数占位有序超胞** —— 最大余数法取整 + 固定种子随机分配，
     成分偏差仅 0.006–0.019。必须如此，因为 **ASE 不支持部分占位**，
     而 CHGNet 的弛豫器走 ASE；
   - `--decor disordered`：`Composition` 部分占位，计量比精确，但**无法弛豫**；
3. `--relax chgnet`（默认）：**CHGNet 通用机器学习势**弛豫（fmax 0.05 eV/Å、300 步），
   实测能量约 −5.98 ~ −6.44 eV/atom（NMC/NCA 组）。

配套改动：`cgcnn_data.build_graph` 的节点特征改为**占位度加权的原子序数 one-hot**。
有序结构（occu=1）退化为普通 one-hot，因此**旧预测完全不变**
（回归验证：LiCoO₂ 仍为 −1.7435 eV/atom、demo 集 MAE 仍为 0.0581）。

### K.3 关键实测：原型 ≠ 真实多晶型

`src/prototype_sensitivity.py` 在**同时有两种结构**的 31 条候选上比较 CGCNN 预测：

| 指标 | bias | MAE | Spearman ρ |
|---|---|---|---|
| 每原子形成能 | **+1.2490 eV/atom** | 1.2594 | −0.053 |
| 带隙 | −1.1172 eV | 1.1818 | 0.365 |

**这不是弛豫不足**，有三条证据：

1. **未弛豫**原型：bias +1.1015、MAE 1.1226 eV/atom；
   **CHGNet 弛豫后**：bias +1.2490、MAE 1.2594 —— 几乎没有变化；
2. **晶胞常数扫描**（未弛豫原型）：

   | a (Å) | 每原子体积 (Å³) | MAE (eV/atom) | bias (eV/atom) |
   |---|---|---|---|
   | 3.80 | 6.86 | 2.216 | +2.216 |
   | 3.90 | 7.41 | 1.379 | +1.379 |
   | 4.00 | 8.00 | 1.186 | +1.178 |
   | 4.10 | 8.62 | 1.123 | +1.102 |
   | 4.20 | 9.26 | 1.123 | +1.088 |

   偏差在 4.0 Å 以上**进入平台**（而 MP 结构每原子体积中位数 10.62 Å³），说明不是体积问题；
3. 物理解释清楚：原型是岩盐型**亚稳**多晶型，MP 给的是该成分的**基态**多晶型
   （如 LiCoO₂ 的层状相、LiFePO₄ 的橄榄石相）。两者本就有 ~1 eV/atom 量级的**多晶型能量差**。

**结论**：结构覆盖率可以从 31/40 提到 40/40，但原型候选的预测**只能组内比较**，
绝不能与 MP 结构候选混排 —— 否则整族原型会被系统性压低（bias +1.25 eV/atom）。
