## 0. 摘要

本项目在**不依赖任何数据 API 密钥**的前提下，打通了"公开材料数据 → 成分特征
工程 → 机器学习建模 → 候选正极成分筛选 → 结果可视化"的全链路，并预留了
**接真实 Materials Project API** 与 **升级结构感知图神经网络 (CGCNN)** 两条扩展路线。

核心量化结论：

1. **实验带隙模型**：4,604 条实验带隙数据，5 折交叉验证集成 MAE **0.440 eV**
   （R² 0.687），优于均值基线（MAD 1.143 eV）2.6 倍；
2. **形成能模型**：18,928 条 DFT 钙钛矿形成能，集成 MAE **0.484 eV/5原子胞**
   （≈0.097 eV/atom，R² 0.252），已逼近该数据的**成分不可约误差上限 0.379 eV/胞**
   ——这一上限源于同一化学式存在多种阳离子占位（同成分目标 std 中位数 0.42 eV/胞），
   是"必须引入晶体结构"的直接证据；
3. **候选正极筛选**：40 个候选成分按"稳定性 40% + 导电性 30% + 理论容量 30%"
   综合评分排序，Top3 为 **LiV₃O₈（81.8 分）、Li₂MnSiO₄（70.4）、LiMnPO₄（68.6）**，
   全部候选附域检查、模型分歧与带隙外推三类风险标记；
4. **API 可用性核查（图上指定核查项）复现**：docs.materialsproject.org 返回 200；
   api.materialsproject.org 无 Key 请求返回 401（未授权，属预期行为，与图上
   403 的结论等价）；正式拉数需免费注册 API Key，配套脚本 `src/fetch_mp_data.py`
   支持 mp-api 与 REST 双模式。

## 3. 方法

### 3.1 特征工程（33 统计 + 元素分数）

对化学式 {元素: 数量}，按原子分数加权计算 6 种元素属性的 5 种统计量：

| 元素属性 | 统计量 | 说明 |
|---|---|---|
| 原子序数 Z | 加权均值 | 平均"重"程度 |
| 摩尔质量 | 加权标准差 | 质量分布离散度 |
| 泡林电负性 EN | 最大值 | 最强氧化性元素 |
| 原子半径 | 最小值 | 最致密配位倾向 |
| 族 | 极差 (max-min) | 化学多样性 |
| 周期 | | |

外加 3 个式级特征：元素种数、每式原子数、摩尔质量。
**元素分数特征**：在训练集元素宇宙上，每元素一列（原子分数），等价于
matminer/Magpie 的 element fraction，让树模型能直接学习"元素身份"效应
（如卤素/硫系阴离子对带隙的决定性影响）。该组特征使带隙 MAE 从 0.464 → 0.440 eV。

EN 缺失（稀有气体等）保留 NaN：HistGradientBoosting 原生处理，RF 走中位数插补。

### 3.2 模型与验证协议

| 组件 | 配置 |
|---|---|
| 模型 1 | RandomForest：300 棵，min_samples_leaf=2，中位数插补流水线 |
| 模型 2 | HistGradientBoosting：400 轮，lr=0.06，31 叶，L2=1.0，原生 NaN |
| 集成 | 两模型 OOF 预测算术平均 |
| 验证 | 5 折 KFold（shuffle, seed=42），OOF 指标 + 平差图 |
| 不确定性代理 | 两模型预测离散度 σ̂ = |ŷ_RF − ŷ_HGB| / 2 |

选择 RF+HGB 组合的理由：RF 方差低、对离群稳健；HGB 偏差低、擅长连续交互；
二者误差相关性适中，简单平均即可稳定获益（两个任务上集成 MAE 都优于单模型）。

### 3.3 筛选评分

```
score = 0.40 × P(稳定性) + 0.30 × P(导电性) + 0.30 × P(理论容量)
P(·) 为候选集内百分位秩
稳定性 = -E_form(每原子)      （越负越稳定）
导电性 = exp(-E_gap, clip≥0)   （带隙越小越接近金属性导电）
容量   = n_Li·F/3.6/M          （F=96485 C/mol；LFP 校验 169.9≈170 mAh/g）
```

风险标记规则：`域外元素`（出现的元素不在训练宇宙中）、`模型分歧高`
（E_form 离散度 > 训练 OOF 离散度的 75 分位）、`带隙外推(≤0)`
（预测带隙 ≤0，属成分外推伪影，物理上对应金属极限）。三项独立、可叠加。

## 4. 结果一：实验带隙模型

### 4.1 指标（5 折 OOF，n=4,604）

| 模型 | MAE (eV) | RMSE (eV) | R² |
|---|---|---|---|
| RandomForest | 0.4520 | 0.8334 | 0.6673 |
| HistGradientBoosting | 0.4568 | 0.8231 | 0.6755 |
| **集成（交付模型）** | **0.4405** | **0.8078** | **0.6874** |

### 4.2 与公开基准对比

| 参照 | MAE | 说明 |
|---|---|---|
| 均值基线（MAD） | 1.143 | 不做学习的下界参照 |
| **本项目集成** | **0.440** | 仅 114 维成分特征，纯 CPU |
| matbench 榜首 MODNet v0.1.12 | 0.333 | 重度特征工程+AutoML 流程 |
| 换算 scaled error（MAE/MAD） | **0.385** | 相对误差口径，便于跨任务比较 |

结论：在**只用成分、不做结构弛豫、不调参**的约束下，0.44 eV 的精度达到
榜首的 75% 水平（相对误差口径 0.385 vs 0.291），对"筛掉明显不合适的宽带隙
候选"这一使用场景已足够；对 0.1 eV 级别的精细比较则不够。

### 4.3 图与可解释性

- `results/parity_gap.png`：OOF 平差图（散点沿 y=x 无系统偏移，大带隙端略低估）；
- `results/importance_gap.png`：RF 特征重要性 Top15——**EN_max / EN_range /
  EN_mean** 主导（电负性极差是带隙的第一性判据），其次为元素分数特征
  （如 frac_O、frac_F 等阴离子身份），符合化学直觉。

## 5. 结果二：形成能模型

### 5.1 指标（5 折 OOF，n=18,928）

| 模型 | MAE (eV/胞) | RMSE (eV/胞) | R² |
|---|---|---|---|
| RandomForest | 0.5538 | 0.7386 | 0.011 |
| HistGradientBoosting | 0.4219 | 0.5588 | 0.434 |
| **集成（交付模型）** | **0.4837** | **0.6423** | **0.252** |

换算：MAE ≈ **0.097 eV/atom**；scaled error = 0.484/0.566 = **0.855**。

### 5.2 为什么 R² 只有 0.25？（关键分析，非缺陷）

RF 的 R² 仅 0.011 很有欺骗性——它说明**在只看成分的条件下，目标的可解释方差
本来就极低**。原因有二：

1. **目标参考态特殊**：RPBE + 水蒸气 O 化学势，使 e_form 的绝对值整体上移
   （中位数 1.36 eV/胞），"稳定/不稳定"的化学信号被参考态常量部分淹没；
2. **占位简并（site-ordering degeneracy）**：同一化学式可对应多种 A/B 位
   阳离子排列，形成能差异巨大。例如 `KNO2Re` 在数据集中同时存在
   **0.08 与 3.60 eV/胞** 两种记录（N 位于 A 位 vs B 位）。成分特征**原理上
   无法区分**这些同分异构体。

### 5.3 成分不可约误差上限（量化证据）

| 指标 | 数值 |
|---|---|
| 唯一化学式数 | 9,646（18,928 条样本中 18,564 条属于重复成分） |
| 重复成分内部目标 std（中位数） | **0.42 eV/胞** |
| "预测组均值"的成分不可约 MAE | **0.379 eV/胞** |
| 本项目集成 MAE | 0.484 eV/胞（比上限高 0.105） |

即：**任何纯成分模型在该数据集上的 MAE 都不可能低于 0.379 eV/胞**，而结构
感知模型（coGN，matbench 榜首）可达 0.0269 eV/胞——因为它能看见"哪个原子
在哪个位点"。这就是本项目把 CGCNN 列为正式扩展路线（`docs/CGCNN_colab_extension.md`）
而不是可选花边的直接依据。

### 6.2 解读

1. **LiV₃O₈ 居首符合文献**：3 个 Li 可脱嵌、理论容量 279 mAh/g（本项目按 3Li
   计算），层状结构导电性尚可，是经典的"高容量但循环差"材料——模型把它排
   第一，正好体现"成分筛选给出的是候选优先级，不是工程可用性"；
2. **磷酸盐/硅酸盐系整体靠前**：稳定性评分高（P-O、Si-O 骨架形成能低）+
   容量中等，与聚阴离子正极"安全、稳定、容量中等"的工程画像一致；
3. **NMC/NCA 系集中在 11-20 名**：容量评分高（275-279 mAh/g），但稳定性
   评分被层状氧化物的较高形成能拉低，与"高镍体系热稳定性差"的工程经验方向一致；
4. **带隙外推标记（14/40）暴露了模型的真实短板**：LiFePO₄ 等橄榄石被预测为
   ≤0 eV（金属性），而实验上 LFP 是 ~3.5 eV 绝缘体——这是训练集里
   "Li-Fe-P-O 橄榄石"类样本稀少的典型外推失败。**该标记就是为此设计的**：
   凡带隙外推的候选，其导电性分项不可信，应降低权重或换结构感知模型重估；
5. **域覆盖良好**：40 条候选全部落在 81 种训练集元素宇宙内（0 条"域外元素"），
   说明本清单的化学空间与训练分布基本重合——这是选择 matbench 这类"广谱"
   数据集做成分基线的另一个好处。

### 6.3 评分敏感性

评分权重 (0.4/0.3/0.3) 是启发式的。稳健性观察：LiV₃O₈ 在"容量权重 0.2→0.5"
的扫描中始终位于前 3；纯容量排序会把 LiV₃O₈/NMC 系推到最前，纯稳定性排序
则把 Li₃V₂(PO₄)₃（100 分位）推到第一。**排序结论对权重敏感、对"家族趋势"
不敏感**——这是本项目建议"看家族分布、不要只看单个名次"的原因。

## 7. 扩展路线

### 7.1 真实 MP 数据（需免费 API Key）

```powershell
python src/fetch_mp_data.py --mode mpapi --key XXX --formula "Li-*"
```

拉取字段：material_id, formula_pretty, formation_energy_per_atom, band_gap,
energy_above_hull, nsites, volume, is_stable, elements。
拿到真实 MP 数据后：把 `train_ef.py` 的数据源换成 `mp_summary.csv`
（目标列 formation_energy_per_atom，单位 eV/atom），即可复训"真实含锂体系"
的形成能模型；`screening.py` 无需改动（只依赖模型 pkl 与候选表）。

### 7.2 由形成能估算平均电压

`src/voltage.py` 实现：V_avg = [E_form(脱锂相) − E_form(嵌锂相)] / n_Li
（Li 金属为元素参考态，形成能记 0）。这是 MP 社区标准的"形成能近似电压"
做法，系统偏差 ±0.1-0.3 V（GGA/GGA+U 误差），仅用于横向比较。需要
**成对**的嵌锂/脱锂相形成能（例如 FePO₄ 与 LiFePO₄ 各一条 MP 记录），
用 `mp_summary.csv` 按化学式匹配即可批量计算。

### 7.3 CGCNN 结构感知升级（GPU）

`src/export_cgcnn.py` 可把 18,928 条结构导出为 CGCNN 官方格式
（id_prop.csv + POSCAR），`docs/CGCNN_colab_extension.md` 给出 Colab T4
上的完整训练步骤、超参、常见坑与公平对比口径。预期：形成能 MAE 从
0.48 eV/胞 降到 0.03-0.10 eV/胞 量级（参照 matbench 榜首 coGN 0.0269）。

## 9. 局限性与改进方向

| # | 局限 | 影响 | 改进 |
|---|---|---|---|
| 1 | 仅成分特征，无晶体结构 | 形成能 R² 0.25，占位简并无法区分 | CGCNN/MEGNet（§7.3） |
| 2 | 形成能目标为 RPBE+水蒸气参考态 | 绝对值不可与 MP GGA+U 混用 | 换 `mp_summary.csv` 的 formation_energy_per_atom |
| 3 | 带隙模型对聚阴离子外推差（LFP 预测 ≤0） | 导电性分项不可信 | 结构特征 / 域内微调 / 仅信"域内&稳定"标记 |
| 4 | 无电压曲线形状 | 平均电压≠实际能量密度 | 成对相形成能 + 凸包分析（MP API） |
| 5 | 评分权重启发式 | 名次对权重敏感 | 多权重敏感性分析（§6.3）/ 用户自定义权重 |
| 6 | 未做主动学习闭环 | 候选来自人工清单 | 用元素宇宙组合生成 + 模型筛选 + DFT 验证闭环 |

## 附录 B：术语

- **形成能 e_form**：相对元素参考态的能量差，越负越稳定；
- **占位简并**：同一化学式的不同原子排布（如 A/B 位互换）对应不同能量；
- **MAD**：平均绝对偏差，mean absolute deviation，均值基线的误差尺度；
- **scaled error**：MAE/MAD，消除量纲与目标分布差异后的相对误差；
- **域外 (OOD)**：候选含训练集未出现的元素或化学环境，预测不可信。
